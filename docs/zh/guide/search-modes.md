# 搜索模式

搜索栏提供四种不同的查词方式。点击搜索栏右侧的**模式按钮**（展开搜索视图后，它也在清空键 ✕ 旁边），即可在四种模式间循环切换。当前模式由图标表示，长按还会显示「搜索模式：正序」之类的提示。你的选择会被保存，下次打开词悦时自动恢复。

四种模式（按循环顺序）：

| 模式 | 图标 | 匹配规则 | 是否需要全文索引 |
| --- | --- | --- | --- |
| 正序（默认） | ⏮ | 词头**以**输入内容开头。 | 否 |
| 倒序 | ⏭ | 词头**以**输入内容结尾。 | 是 |
| 多词 | 🔗 | 词头**同时包含**输入的每个词，不要求相邻。 | 是 |
| 全文 | 🔍 | 在**释义**中匹配，而非仅词头。 | 是 |

## 正序 —— 默认模式

词头以你输入内容开头的词条，例如输入 `app` 会得到 `apple`、`application`。这是词悦原本的查词行为，无需任何设置——词典载入后即可使用。

## 倒序 —— 逆引词典

词头**以**输入内容**结尾**的词条，可以「揪着尾巴查词」。这正是倒序词典（逆引词典）的思路：当你只记得结尾、想不起完整词条时，输入结尾字即可列出所有以它收尾的词。例如只记得「×动」、想不起「翕动」，输入「动」会列出按兵不动、摆动、半自动、暴动、被动……再从中挑出想找的那个。

倒序匹配由全文索引中新增的「反转词头」列提供，因此依赖该索引（见下文）。

## 多词 —— 多词组合

词头**同时包含**你输入的每一个字，顺序不限、不要求相邻。例如输入「中国」或「中 国」，结果里既有二字相邻、正序的「中国」，也有相邻但倒序的「国中」，以及包含相邻「中国」二字的「中国通」「大秦景教流行中国碑」、被其他字隔开的「中立国」「中华民国鄂州约法」「中华民国北伐铁血团」……每个词头都同时含有「中」和「国」，但二者不必相邻、也不必按序，是「正序」「倒序」都表达不了的意图。

## 全文 —— 检索释义

在**释义内容**中匹配你的输入，而不只是词头。输入一个概念或短语，词悦会列出所有正文提及它的词条，并附上上下文片段。其引擎与独立的「在释义中搜索」一致，现在直接集成到了搜索栏中。

## 全文索引

倒序、多词、全文三种模式都读取**全文索引**（词悦按词典逐个构建），正序不使用它。

首次使用这三种模式之一时，词悦会在后台开始构建索引——与全文页进行的构建相同。在索引就绪之前，搜索栏会以状态行代替结果：

- **正在构建……** —— 索引正在生成，完成后结果自动出现。
- **索引未构建** —— 点击它打开全文页，在那里构建并显示进度。
- **索引构建失败** —— 点击它到全文页重试。

你也可以一次性构建和管理所有词典的索引：**设置 → 管理词典 → 索引总览图标**，那里列出每本词典的索引状态、磁盘占用，以及构建 / 取消 / 重建等操作。
