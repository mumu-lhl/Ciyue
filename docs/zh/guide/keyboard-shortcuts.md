# 键盘快捷键

词悦的快捷键沿用 [GoldenDict-ng](https://github.com/xiaoyifang/goldendict-ng) 与 [EBWin](https://ebstudio.info/manual/EBWin4/EBWin4.html)、[EBMac](https://ebstudio.info/manual/EBMac/index.php) 的习惯：在其它词典里已经用顺手的键，在这里沿袭。

其中大部分**仅限桌面端**，因为Android版Flutter对激活键盘快捷键的焦点有问题。在 Android 上，除了少数快捷键，大部分快捷键都会因为焦点不知道跑哪去了，而不能稳定地激活。不过好在会用到键盘输入的安卓设备也有限——通常只有GPD Win Max、壹号游侠这样的UMPC上的Waydroid，某些自带键盘的安卓平板、手机会用到快捷键。而对UMPC来说，可以直接使用桌面版词悦。

## 两个层级

与词典有关的快捷键分两层：

```
Ctrl+`  /  Ctrl+1…9      分组：查词时用哪些词典
        │
        └── Alt+0…9       词典：看哪一部词典的结果
                            Alt+0 = AI 解释，Alt+1…9 = 第 1…9 部词典
                            Alt+PgUp / Alt+PgDn = 上一个 / 下一个标签
```

## 查词

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+`F` | 把焦点移进搜索框 |
| `Esc` | 把焦点移进搜索框，**并选中框里的文字**，直接输入即可覆盖；再按一次回到词条 |
| 选中文字后按 `Enter` | 查选中的文字（见下） |
| 选中文字后按 `Ctrl`+`Enter` | 在新标签页里查，相当于对链接按 `Ctrl`+点击 |

宽窗口里有两个搜索框：左栏的那个，和词条标题栏里的那个。`Ctrl`+`F` 和 `Esc` 会落到你最后用过的那个，跟着你在窗口里走动，而不是每次都落在左边那个。

### 查选中的文字

在释义里选中一个词或一个短语，按 `Enter` 即可查词。这是 EBWin、EBMac 的做法，在桌面端这也是目前唯一的选词查词途径——释义页的右键菜单是 Chromium 自带的，只提供复制和检查元素。

「选中再按回车查询」比「直接双击一个单词查询」好用，因为在那些不用空格分词的语言里，双击能选到啥就只能看人品了；而且即便是英语这样的语言，有时也会遇到复合词和短语动词，直接双击查不到：

| 语言 | 需要查询的词汇 | 单击选中整个单词 |
|---|---|---|
| 德语 | `Bundesbankdirektor` 里的 `Bundesbank` | `Bundesbankdirektor` |
| 日语 | `日本語辞典` 里的 `日本語` | `日本語辞典` |
| 汉语 | `现代汉语词典` 里的 `汉语` | `现代汉语词典` |
| 英语 | `throw away` | `throw` 或者 `away` |

在 Android 上，长按菜单里也有同样的查词项，旁边是复制和朗读；用鼠标右键点一个词也会选中它，菜单里的「查询」查的就是这个词。

## 标签

词悦里有三种标签，很容易混。

### 单词标签

顶部那排类似浏览器的标签，每个标签放一个词。

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+`T` | 新建标签 |
| `Ctrl`+`W` | 关闭当前标签 |
| `Ctrl`+`Tab` | 下一个标签 |
| `Ctrl`+`Shift`+`Tab` | 上一个标签 |
| `Ctrl`+`PgDn` / `Ctrl`+`PgUp` | 下一个 / 上一个标签 |

从词表打开的一组词条里，`←` / `→` 翻到上一个 / 下一个词。桌面端同样有效，不限于移动端的全屏列表。

### 词典分组

分组决定查词时用哪些词典。分组按创建顺序列在窗口顶部的菜单里，快捷键也按这个顺序编号。

| 快捷键 | 作用 |
|---|---|
| `Ctrl` + 反引号 | 切到第一个分组，即默认分组 |
| `Ctrl`+`1` … `Ctrl`+`9` | 切到第二个到第十个分组 |

超出分组数量的数字不做任何事。切换之后，当前屏幕上的词会用新分组的词典重新查一遍。

### 词典标签

词典切换样式为**标签式**时，每部词典在释义区里有一个标签，数字键用来挑其中之一。

| 快捷键 | 作用 |
|---|---|
| `Alt`+`1` … `Alt`+`9` | 显示第 1 到第 9 部词典 |
| `Alt`+`0` | 显示 AI 解释（需要开启该功能） |
| `Alt`+`PgUp` | 显示上一个词典标签 |
| `Alt`+`PgDn` | 显示下一个词典标签 |

到头会绕回另一端（和 `Ctrl`+`Tab` 的单词标签一样）。开启 AI 解释时，AI 标签也在这串标签里。相对切换不受 9 部的数量限制，第 10 部往后的词典也能到达。

**展开式**下没有这些标签，这组键完全不做任何事。

## 朗读

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+`R` | 朗读当前词；正在朗读时再按一次则停止 |
| `Ctrl`+`Shift`+`S` | 停止播放 |
| `Alt`+`↑` / `Alt`+`↓` | 在历史记录里选上一个 / 下一个词 |
| `Alt`+`←` / `Alt`+`→` | 在词条历史里后退 / 前进 |
| `PgDn` / `PgUp` | 展开式下翻页 |

## 缩放释义

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+= / `Ctrl`++ | 放大释义 |
| `Ctrl`+- | 缩小释义 |
| `Ctrl`+`0` | 恢复默认大小 |

只有释义会被缩放，窗口的其它部分保持原样。缩放级别会被记住，重启后依然有效；[词典外观](/zh/guide/appearance) 里也有对应的滑块。

大多数键盘上 `Ctrl`+= 和 `Ctrl`++ 是同一个键，两者都绑定了，按哪个都行。

## 其它页面

| 快捷键 | 作用 | 位置 |
|---|---|---|
| `Ctrl`+`Enter` | 翻译文本 | 翻译 |
| `Ctrl`+`Enter` | 检查文本 | 写作检查 |
| `Space` | 显示答案 | 抽认卡 |
| `1` … `4` | 评价卡片 | 抽认卡 |

## 鼠标手势（仅桌面）

在释义区可以用两个鼠标手势切换标签。**设置 → 外观** 里能为每个手势分别选择动作：关闭、切换词典标签、切换单词标签。

| 手势 | 操作 | 默认动作 |
|---|---|---|
| 摇杆手势 | 按住**左键**，再点一下**右键** | 切到下一本词典标签 |
| 滚轮手势 | 按住**中键**，向上 / 向下滚动 | 切到上一个 / 下一个单词标签 |

摇杆手势只做这一个方向：词典标签是循环切换的，多按几次转一圈就能回来，所以不需要反向。滚轮手势是双向的，适合在开了好几个词的单词标签之间来回找。

**展开式**下没有词典标签，此时「切换词典标签」会自动退化为「切换单词标签」，不会按了没反应。

- 只在 Windows、Linux、macOS 上生效；Android 没有右键和滚轮。
- 普通右键点击不受影响，只有左键按住时才会抑制右键菜单。macOS 的 `Ctrl`+左键是系统模拟的右键，不参与手势，仍走原来的行为。
- 滚轮手势做了节流，一次滚动不会连跳好几个标签；按住中键时页面自身的滚动会被阻止。
- 手势触发后紧随的那次点击会被拦掉，不会误开词条链接。

## 说明

- 分组与词典标签的快捷键只在释义页在前台时生效。
- 如果窗口管理器占用了 `Alt`+数字，就没法用这组键切换词典标签。
- `Ctrl`+`PgUp` 与 `Ctrl`+`PgDn` 切的是单词标签，`Alt`+`PgUp` 与 `Alt`+`PgDn` 切的是词典标签；单独按这两个键（不带修饰键）在展开式下用来翻页。
- 带修饰键的快捷键在释义区（原生 WebView）持有焦点时也能触发，不依赖焦点落在哪个控件上；裸 `PgUp`/`PgDn` 仍留给释义区滚动和输入框。
- 历史导航只用 `Alt`+`↑`/`↓`：macOS 的调度中心占用 `Ctrl`+`↑`/`↓`，KDE、GNOME、Windows 的窗口平铺占用 `Super`/`Win`+`↑`/`↓`，`Alt` 是主流桌面都留空的那一组。macOS 输入框里 `Option`+`↑`/`↓` 是「段落首 / 尾」，焦点在搜索框时词悦会让位给输入框。
- 桌面布局下，方向键用于在控件之间移动焦点，`Enter` 或 `Space` 激活当前聚焦的控件。
