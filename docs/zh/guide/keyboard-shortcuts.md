# 键盘快捷键

词悦的快捷键沿用 [GoldenDict-ng](https://github.com/xiaoyifang/goldendict-ng) 与 EBWin 的习惯：在其它词典里已经用顺手的键，在这里做同样的事。

其中大部分**仅限桌面端**，因为它们需要实体键盘。在 Android 上基本用不上，除非外接了蓝牙键盘。

## 两个层级

与词典有关的快捷键分两层：

```
Ctrl+`  /  Ctrl+1…9      分组：查词时用哪些词典
        │
        └── Alt+0…9       词典：看哪一部词典的结果
                            Alt+0 = AI 解释，Alt+1…9 = 第 1…9 部词典
```

## 查词

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+`F` | 把焦点移进搜索框 |
| `Esc` | 把焦点移进搜索框，**并选中框里的文字**，直接输入即可覆盖；再按一次回到词条 |
| 选中文字后按 `Enter` | 查选中的文字（见下） |

### 查选中的文字

在释义里选中一个词或一个短语，按 `Enter` 即可查词。这是 EBWin 的做法，在桌面端这也是唯一的选词查词途径——释义页的右键菜单是 Chromium 自带的，只提供复制和检查元素。

选中比双击好用，因为双击在那些不用空格分词的语言里永远只能选中词的一部分：

| 语言 | 双击选到 | 选中整个短语得到 |
|---|---|---|
| 德语 | `Bundesbankdirektor` 里的 `Bundesbank` | `Bundesbankdirektor` |
| 日语 | `日本語词典` 里的 `日本` | `日本語词典` |
| 中文 | `现代汉语词典` 里的 `现代` | `现代汉语词典` |

在 Android 上，长按菜单里也有同样的查词项，旁边是复制和朗读；用鼠标右键点一个词也会选中它，菜单里的「查询」查的就是这个词。

## 标签

词悦里有三种标签，很容易混。

### 单词标签

顶部那排类似浏览器的标签，每个标签放一个词。

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+`T` | 新建标签 |
| `Ctrl`+`W` | 关闭当前标签 |
| `Ctrl`+`Tab` | 下一个标签 |
| `Ctrl`+`Shift`+`Tab` | 上一个标签 |
| `Ctrl`+`PgDn` / `Ctrl`+`PgUp` | 下一个 / 上一个标签 |

在移动端的全屏单词列表里，`←` / `→` 翻到上一个 / 下一个词。

### 词典分组

分组决定查词时用哪些词典。分组按创建顺序列在窗口顶部的菜单里，快捷键也按这个顺序编号。

| 快捷键 | 作用 |
|---|---|
| `Ctrl` + 反引号 | 切到第一个分组，即默认分组 |
| `Ctrl`+`1` … `Ctrl`+`9` | 切到第二个到第十个分组 |

超出分组数量的数字不做任何事。切换之后，当前屏幕上的词会用新分组的词典重新查一遍。

### 词典标签

词典切换样式为**标签式**时，每部词典在释义区里有一个标签，数字键用来挑其中之一。

| 快捷键 | 作用 |
|---|---|
| `Alt`+`1` … `Alt`+`9` | 显示第 1 到第 9 部词典 |
| `Alt`+`0` | 显示 AI 解释（需要开启该功能） |

**展开式**下没有这些标签，这组键完全不做任何事。

## 朗读

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+`R` | 朗读当前词 |
| `Ctrl`+`Shift`+`S` | 停止播放 |
| `Ctrl`+`↑` / `Ctrl`+`↓` | 在历史记录里选上一个 / 下一个词 |

## 缩放释义

| 快捷键 | 作用 |
|---|---|
| `Ctrl`+= / `Ctrl`++ | 放大释义 |
| `Ctrl`+- | 缩小释义 |
| `Ctrl`+`0` | 恢复默认大小 |

只有释义会被缩放，窗口的其它部分保持原样。缩放级别会被记住，重启后依然有效；[词典外观](/zh/guide/appearance) 里也有对应的滑块。

大多数键盘上 `Ctrl`+= 和 `Ctrl`++ 是同一个键，两者都绑定了，按哪个都行。

## 其它页面

| 快捷键 | 作用 | 位置 |
|---|---|---|
| `Ctrl`+`Enter` | 翻译文本 | 翻译 |
| `Ctrl`+`Enter` | 检查文本 | 写作检查 |
| `Space` | 显示答案 | 抽认卡 |
| `1` … `4` | 评价卡片 | 抽认卡 |

## 说明

- 分组与词典标签的快捷键只在释义页在前台时生效。
- 如果窗口管理器占用了 `Alt`+数字，就没法用这组键切换词典标签。
- `Ctrl`+`PgUp` 与 `Ctrl`+`PgDn` 切的是单词标签；单独按这两个键（不带 `Ctrl`）在展开式下用来翻页。
- 桌面布局下，方向键用于在控件之间移动焦点，`Enter` 或 `Space` 激活当前聚焦的控件。
