Ciyue runs on Android, Windows, Linux, and macOS.

### Windows

Download the installer (`ciyue-installer.exe`) or portable ZIP from the [latest release](https://github.com/mumu-lhl/Ciyue/releases/latest).

### Linux

- **Flatpak**: download `ciyue-x86_64.flatpak` from a release and install it with:

  ```bash
  flatpak install --user ./ciyue-x86_64.flatpak
  ```

- **Arch Linux**: install from the [AUR](https://aur.archlinux.org/packages/ciyue) or [archlinuxcn](https://github.com/archlinuxcn/repo/tree/master/archlinuxcn/ciyue) repository:

  ```bash
  yay -S ciyue
  ```

- **AppImage**:
  - via [AppMan](https://github.com/ivan-hc/AppMan) (rootless): `appman -i ciyue`
  - via [AM](https://github.com/ivan-hc/AM): `am -i ciyue`

### macOS

Download the DMG (`ciyue-macos.dmg`) from the [latest release](https://github.com/mumu-lhl/Ciyue/releases/latest).

Ciyue needs macOS 12 (Monterey) or later. The DMG is a universal build, so it runs on both Apple Silicon and Intel Macs. Launch at login needs macOS 13 (Ventura) or later; on macOS 12 the setting has no effect.

## Nightly

Nightly builds are published every night from the latest main branch. They include the newest features, but may be unstable. Download the [latest nightly build](https://github.com/mumu-lhl/Ciyue/releases/tag/nightly).

## After installing

Ciyue does not ship with dictionaries. See [Download dictionaries](./guide/getting-started#download-dictionaries) to add your first dictionary.
