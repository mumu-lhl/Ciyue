快速上手 ​

安装 ​

Android ​

小提示：Obtainium 直接跟踪 GitHub releases，更新比 F-Droid 快（F-Droid 的构建发布会有延迟）。

Windows ​

从 latest release 下载安装包（ciyue-setup.exe）或绿色版 ZIP。

Linux ​

  • Flatpak：从 release 下载 ciyue-x86_64.flatpak 后安装：

    bash
    flatpak install --user ./ciyue-x86_64.flatpak

  • Arch Linux：从 AUR 或 archlinuxcn 仓库安装：

    bash
    yay -S ciyue

  • AppImage：

    • 通过 AppMan（免 root）：appman -i ciyue
    • 通过 AM：am -i ciyue

macOS ​

从 latest release 下载 DMG（ciyue-macos.dmg）。

下载词典 ​

词悦不自带词典。从 Wiki 的推荐词典下载 .mdx / .mdd 文件，或者 StarDict 词典（.ifo / .idx / .dict），然后在 设置 → 管理词典 中添加。

云同步 ​

在多设备间同步单词本、标签、抽认卡和历史记录。见云同步设置。

Android 上的 KOReader ​

在 koreader 目录下创建 dictionaries.lua 文件：

lua
{
    { "Ciyue", "Ciyue", false, "org.eu.mumulhl.ciyue", "send" }
}
