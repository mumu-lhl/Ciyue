翻译 ​

词悦的翻译页用于在不同语言之间翻译文本。与传统的单引擎翻译不同，它可以同时向多个源查询——免费网络服务、官方 API 和 AI 服务商——每个结果单独成卡展示，你可以把 Google、DeepL 和某个大模型对同一句话的翻译并排比较，挑最好的一个。

使用翻译 ​

  1. 打开翻译页，输入或粘贴文本。
  2. 选择源语言和目标语言（源语言默认为自动检测），或点交换按钮互换两者。
  3. 点翻译。所有启用的源会被并行请求，结果按返回速度陆续填入卡片。桌面端可按 Ctrl+Enter 翻译。
  4. 每张卡片都有朗读和复制按钮。部分源（如 DeepL Free）还会返回备选译文，以 chip 形式显示在主结果下方，点一下即可复制。

某个源失败只会影响它自己的卡片，不影响其他结果。

管理翻译源 ​

从翻译页打开翻译设置，可以看到源列表：

  • 开关：逐个启用/停用，至少保留一个启用。
  • 排序：按住拖动手柄调整顺序，结果卡片按同一顺序排列。
  • 配置：需要配置的源会显示「已配置 / 未配置」，展开后填写所需字段。
  • 已启用但未配置的源在翻译时会被跳过，并在结果下方给出提示。

升级后默认只启用你原来用的那个源，原有行为不变。

AI 服务商作为翻译源 ​

在设置 → AI 中配置过的每个 AI 服务商（OpenAI、Gemini、DeepSeek、Anthropic、OpenRouter、SiliconFlow、智谱、xAI、Ollama 等）也都是一个翻译源。判定「已配置」的标准是 AI 设置里填了模型和 API Key（Ollama 等本地服务不需要 Key）。你可以同时启用多个 AI 服务商，和机器翻译源放在一起对比效果。AI 的结果按 markdown 渲染，配合翻译设置里的富文本输出模式效果更好。

标注为免费的翻译源调用的是各服务商网页端或客户端的公开接口，并非服务商提供的官方开放 API。服务商可能随时变更、限制或终止这类接口，使用它们也可能不符合相应服务商的服务条款。本应用仅将它们作为可选项提供，是否启用由您自行决定，相关风险由您自行承担。

需要 API Key 的源使用您自行申请的凭据，产生的费用、配额与合规责任由您与服务商之间解决。

您输入的翻译文本会被直接发送至您所启用的每个翻译源的服务器，请勿翻译您不希望第三方处理的内容。词悦本身不收集、不上传您的翻译内容。

如果某个免费源突然不能用了，多半是服务商变更或封禁了接口，并不是词悦的 bug。请停用该源、改用其他源，或换成官方 API 源。
