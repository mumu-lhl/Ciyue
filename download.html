On this page

Download ​

Ciyue runs on Android, Windows, Linux, and macOS.

Stable ​

Download the latest release — recommended for most users.

Android ​

Tip: Obtainium tracks GitHub releases directly, so you get updates faster than F-Droid, whose builds can lag behind.

Windows ​

Download the installer (ciyue-setup.exe) or portable ZIP from the latest release.

Linux ​

  • Flatpak: download ciyue-x86_64.flatpak from a release and install it with:

    bash
    flatpak install --user ./ciyue-x86_64.flatpak

  • Arch Linux: install from the AUR or archlinuxcn repository:

    bash
    yay -S ciyue

  • AppImage:

    • via AppMan (rootless): appman -i ciyue
    • via AM: am -i ciyue

macOS ​

Download the DMG (ciyue-macos.dmg) from the latest release.

Ciyue needs macOS 12 (Monterey) or later. The DMG is a universal build, so it runs on both Apple Silicon and Intel Macs. Launch at login needs macOS 13 (Ventura) or later; on macOS 12 the setting has no effect.

Nightly ​

Nightly builds are published every night from the latest main branch. They include the newest features, but may be unstable. Download the latest nightly build.

After installing ​

Ciyue does not ship with dictionaries. See Download dictionaries to add your first dictionary.
