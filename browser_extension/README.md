# 词悦 (Ciyue) 浏览器查词扩展

词悦桌面端的配套浏览器扩展插件，让您在浏览网页、阅读外文文献时享受秒级划词查词、离线本地词典渲染、音频发音及生词本一键同步。

---

## ✨ 功能特性

1. **即时划词查词**：在网页中选中任意单词，鼠标旁即刻弹出「悦」字查词浮标，点击展开精美的 MDX 词典释义弹窗。
2. **快捷键唤起**：选中文字后按 `Alt + Q`，立即呼出查词卡片。
3. **右键菜单查词**：选中任意文本，右键选择「在词悦中查询」。
4. **工具栏快速查词**：点击浏览器右上角词悦图标，输入单词即可实时联想与查词。
5. **本地离线多词典**：直接读取词悦已加载的离线词典集群（MDX/MDD、StarDict、ZIM），秒级响应。
6. **生词本云同步**：在查词弹窗中点击星标「★」，实时同步到词悦本地生词本。

---

## 🚀 安装步骤 (Chrome / Edge / Brave 等 Chromium 浏览器)

1. **打开词悦桌面端并开启服务**：
   - 进入词悦「设置」->「Web 与 API 服务」。
   - 打开「启用 Web 与 API 服务」开关（默认监听 `http://127.0.0.1:47117`）。

2. **在浏览器中加载扩展**：
   - 打开 Chrome 或 Edge，访问扩展管理页面：
     - Chrome: `chrome://extensions/`
     - Edge: `edge://extensions/`
   - 打开右上角的 **「开发者模式」 (Developer mode)** 开关。
   - 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
   - 在弹出的文件选择器中，选中词悦项目下的 **`browser_extension`** 文件夹。

3. **开始使用**：
   - 在任意网页选中一个英文单词，鼠标旁即会浮现查词图标！

---

## ⚙️ 配置说明

点击扩展图标右键选择「选项」或在扩展管理页点击「详细信息」->「扩展选项」，可修改：
* **词悦服务地址**：默认为 `http://127.0.0.1:47117`。
* **网页划词浮标**：可开启或关闭鼠标选中文本时的浮标提示。
