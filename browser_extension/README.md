# 词悦 (Ciyue) 浏览器查词扩展

词悦桌面端的配套浏览器扩展插件，让您在浏览网页、阅读外文文献时享受秒级划词查词、离线本地词典渲染、AI 深度解析与翻译、音频发音及生词本一键同步。

本项目基于现代化的浏览器扩展框架 **[WXT](https://wxt.dev/)**、**Svelte 5 (Runes 响应式)** 与 **TypeScript** 构建，轻量、高效、极小内存占用。

---

## ✨ 功能特性

1. **即时划词与双击查词**：在网页中选中单词，鼠标旁即刻弹出「悦」字查词浮标；支持配置双击单词直接呼出查词卡片。
2. **防误触高级配置**：支持设置修饰键触发（如按住 `Alt` / `Ctrl` 划词）、自动排除输入框/文本编辑区域、支持配置域名黑名单。
3. **AI 深度解析与长文翻译**：无缝对接词悦桌面端的 AI 引擎，支持流式 SSE 响应、Markdown 格式化高亮排版与一键复制。
4. **快捷键与右键菜单**：
   - 快捷键唤起：选中文字后按 `Alt + Q` 立即查词（可在浏览器快捷键管理中自定义）。
   - 右键菜单：选中文本右键「在词悦中查询」。
5. **本地离线多词典**：直接读取词悦已加载的离线词典集群（MDX/MDD、StarDict、ZIM），秒级响应。
6. **暗黑模式与高度动态自适应**：内置 DarkReader 离线样式注入，通过 ResizeObserver 动态计算内容高度，拒绝双重滚动条。
7. **HTTPS 混合内容安全隔离**：API 请求通过 Background Service Worker 代理通道发起，彻底解决 HTTPS 网页下的 Mixed Content 拦截问题。
8. **生词本实时同步**：在查词卡片中点击星标「★」，实时同步到词悦本地生词本。

## 🛠️ 开发与构建

本项目使用 **pnpm** 作为包管理器。

```bash
# 进入扩展目录
cd browser_extension

# 安装依赖
pnpm install

# 启动开发服务器（支持 HMR 热更新）
pnpm dev

# 代码格式化与校验 (oxfmt & oxlint)
pnpm format
pnpm lint

# 运行单元测试 (vitest + wxt/testing)
pnpm test

# 编译生产版本（产物输出至 .output/chrome-mv3）
pnpm build

# 打包发布为 zip 压缩包
pnpm zip
```

## 🚀 安装步骤 (Chrome / Edge / Brave 等 Chromium 浏览器)

1. **打开词悦桌面端并开启服务**：
   - 进入词悦「设置」->「Web 与 API 服务」。
   - 打开「启用 Web 与 API 服务」开关（默认监听 `http://127.0.0.1:47117`）。

2. **编译扩展产物**：
   - 在 `browser_extension` 目录下执行 `pnpm build`。

3. **在浏览器中加载扩展**：
   - 打开浏览器扩展管理页面：
     - Chrome: `chrome://extensions/`
     - Edge: `edge://extensions/`
   - 打开右上角的 **「开发者模式」 (Developer mode)** 开关。
   - 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
   - 在弹出的文件选择器中，选中 **`browser_extension/.output/chrome-mv3`** 目录。

4. **开始使用**：
   - 在任意网页选中英文单词，鼠标旁即会浮现查词图标！

## ⚙️ 扩展选项配置

右键扩展图标选择「选项」或点击右上角弹出面板的设置齿轮 ⚙️：

- **服务地址**：默认为 `http://127.0.0.1:47117`，支持一键「测试连接」检查连通状态。
- **查词触发方式**：
  - 开启/关闭划词浮标
  - 开启/关闭双击单词直接查词
  - 划词修饰键要求（无需按键 / Alt / Ctrl / Shift）
  - 输入框及可编辑区禁用
- **网址黑名单**：自定义不注入查词脚本的网站域名。
