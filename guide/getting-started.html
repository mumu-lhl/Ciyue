Getting Started ​

Install ​

Android ​

Tip: Obtainium tracks GitHub releases directly, so you get updates faster than F-Droid, whose builds can lag behind.

Windows ​

Download the installer (ciyue-setup.exe) or portable ZIP from the latest release.

Linux ​

  • Flatpak: download ciyue-x86_64.flatpak from a release and install it with:

    bash
    flatpak install --user ./ciyue-x86_64.flatpak

  • Arch Linux: install from the AUR or archlinuxcn repository:

    bash
    yay -S ciyue

  • AppImage:

    • via AppMan (rootless): appman -i ciyue
    • via AM: am -i ciyue

macOS ​

Download the DMG (ciyue-macos.dmg) from the latest release.

Download dictionaries ​

Ciyue does not ship with dictionaries. See the recommended dictionaries on the Wiki, then add your .mdx / .mdd files in Settings → Manage dictionaries.

Cloud sync ​

Keep your wordbook, tags, flashcards, and history in sync across devices. See Cloud sync setup.

KOReader on Android ​

Create dictionaries.lua under directory koreader:

lua
{
    { "Ciyue", "Ciyue", false, "org.eu.mumulhl.ciyue", "send" }
}
